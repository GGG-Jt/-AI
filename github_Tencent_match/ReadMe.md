## 一、作品简介

**文境剧场 AI** 是一款面向中学语文课堂的 AI 教学工具，核心理念是「让每一篇课文都变成一场沉浸式课堂剧场」。教师输入课文原文，系统调用大语言模型自动生成五幕课堂表演剧本、角色卡、场景设计、互动题目、历史拓展故事等全套课堂素材，并支持全屏演示模式和一键导出 Word/PPT 课件。系统预置《荆轲刺秦王》演示案例，同时支持任意文言文课文动态生成，教师可灵活选择学段、课堂风格和表演时长。

---

## 二、作品解决的教育痛点

当前中学文言文教学面临三大核心痛点：**第一，学生学习被动化**——文言文课堂以教师讲解字词和逐句翻译为主，学生处于被动接收状态，难以真正进入文本情境，对人物性格和情感变化缺乏切身感受；**第二，备课负担沉重**——教师若想设计课堂表演或互动环节，需要耗费大量时间编写剧本、设计角色、制作 PPT，从构思到落地往往需要数小时甚至数天；**第三，课堂展示手段单一**——传统的 PPT 课件只能静态展示文字和图片，缺乏沉浸感和剧场氛围，难以将《荆轲刺秦王》《鸿门宴》等叙事性课文的戏剧张力直观呈现给学生。文境剧场 AI 针对以上三个痛点，用 AI 生成替代人工编写，用沉浸式全屏演示替代静态 PPT，用课堂表演替代被动听讲，让文言文教学真正「活」起来。

## 三、作品的核心创意点

本作品的核心创意在于**将文言文教学从「阅读理解」升级为「情境演绎」**。具体体现在四个方面：

1. **一键式内容生产闭环**——用户输入课文后，系统自动产出剧本、角色卡、场景设计、互动题、总结评价等全套课堂素材，无需教师逐一准备。
2. **沉浸式全屏课堂演示**——内置的全屏演示模式按教学逻辑组织幻灯片（封面→背景→人物→角色卡→五幕场景→互动题→总结→启发），支持方向键翻页、空格键自动播放和场景背景图切换，互动题采用「题目页+答案页」双页设计方便引导学生先思后答，完全可替代传统 PPT。
3. **四种课堂风格任意切换**——同一篇课文可生成严肃历史风、生动课堂风、轻松幽默风、公开课展示风四种不同风格的内容，适配不同课堂场景。
4. **LLM 优先 + 预置兜底双轨策略**——优先调用大语言模型动态生成内容，当 API 不可用或网络异常时自动回退到精心设计的预置案例，确保系统在任何环境下都能完整运行。

## 四、作品功能与使用场景

**适用人群**：主要为中学语文教师（课堂备课与演示），也适用于学生（自主预习、角色理解、课后自测）和学校语文教研组（公开课、教学比赛筹备）。

### 核心功能

1. **AI 剧本生成**：自动将课文改编为五幕课堂表演剧本，每幕含舞台背景描述、主持人旁白、角色对话与动作提示、教学点拨。
2. **角色卡系统**：为每个主要角色生成身份、性格特点、表演指导、经典台词和思考问题，帮助学生理解人物。
3. **AI 场景背景图**：对接通义万相和硅基流动 API 生成场景背景图，未配置 API Key 时自动使用本地渐变背景图。
4. **课堂互动题目**：自动生成 6 道覆盖选择题、判断题、简答题、讨论题的互动题目，含答案解析。
5. **历史拓展故事**：补充三篇基于真实史料的历史拓展，帮助学生理解文本的时代背景。
6. **全屏课堂演示模式**：一键进入全屏放映，支持键盘操控和自动播放，配合 AI 背景图营造剧场沉浸感。
7. **文件导出**：支持 Word（完整剧本/按角色分剧本/全部角色合订本）和 PPT（16:9 宽屏含封面、背景图、角色卡、互动题）两种格式的一键导出。

### 典型使用场景

- **常规课堂表演教学**：教师输入课文后分发角色卡和剧本，课堂上用演示模式播放旁白和背景图，学生按角色表演，演完后用互动题讨论复习。
- **公开课/教学比赛**：选择「公开课展示风」生成兼具学术性与表现力的方案，导出精美 PPT 直接用于比赛展示。
- **语文社团/校本课程**：用「轻松幽默风」将经典文言文改编为活泼剧本，打印后组织学生排演，激发兴趣。
- **跨学科融合教学**：结合历史拓展故事模块，从文学和历史双重视角引导学生理解文本。
- **学生自主学习**：输入正在学习的文言文，通过角色卡加深人物理解，用互动题自测掌握程度。

## 五、技术实现说明

**前端**采用原生 HTML/CSS/JavaScript 构建单页应用（SPA），无第三方前端框架依赖，实现背景粒子动画、Label 标签切换、流式进度展示和全屏演示模式。

**后端**基于 Python Flask 框架提供 RESTful API，支持 JSON 和 SSE（Server-Sent Events）流式数据传输。

**文本生成**通过 OpenAI 兼容接口调用大语言模型（优先硅基流动 Qwen2.5-7B-Instruct，备用通义千问 qwen-plus），以结构化 Prompt 让模型输出包含剧本、角色卡、题目、总结等全部字段的完整 JSON，后端解析后进行字段校验和补全。

**图片生成**对接硅基流动 SD3/SDXL 和通义万相 wanx2.1-t2i-turbo，未配置 API Key 时使用 PIL 库按场景主题（危机→暖金色、易水→冷蓝色、秦廷→暗金色等）实时生成精美渐变背景图并叠加场景标题。

**文档导出**基于 python-docx 实现 Word 剧本的格式化排版输出（含角色简介、台词、动作提示和教学批注），基于 python-pptx 实现 16:9 宽屏 PPT 导出（含封面、背景图、角色卡和题目/答案双页布局）。

**双轨策略**方面，优先调用 LLM 动态生成，失败时自动回退到预置的《荆轲刺秦王》完整数据集，确保系统任何条件下均可完整演示全部功能。
